# Bhrashtachar Mukt - Bharat 🇮🇳
### Nazar Sab Pe. Saboot Pakka.

**Mission:** Viksit Bharat @2047 ka Sankalp - Zero Corruption
**Tagline:** "Aam Janta ki Awaaz, Blockchain ki Taakat"

---

### 1. PROJECT KYA HAI?
`Bhrashtachar Mukt - Bharat` ek AI + Blockchain based platform hai.
Iska maksad hai har aam nagrik ko bina darr ke corruption report karne,
track karne aur proof save karne ki taakat dena.

Gaon se lekar Secretariat tak, har jagah pardarshita lane ke liye banaya gaya hai.

### 2. MEGA PRO FEATURES - V2.0

| Feature | Kaam | Status |
| --- | --- | --- |
| **Proof Vault** | Photo, Video, Audio + GPS + Time. IPFS + Blockchain pe lock | ✅ Ready |
| **AI Sher** | Ek Vibhag me 3+ complaint = Auto Red Alert to DM/CVC | ✅ Ready |
| **Awaaz Report** | 60 Sec Voice Note se complaint. Hindi/Bhojpuri/Magahi | 🚀 Future |
| **100% Anonymous** | Na Naam, Na Number. Puri Privacy | ✅ Ready |
| **RTI Machine** | 1 Click me Legal RTI + Appeal PDF Auto Generate | 🚀 Future |
| **Parkhadarshita Score** | Har Jila, Har Vibhag ka 0-100 Score. Public Ranking | ✅ Ready |
| **7-Day Rule** | Officer ke paas 7 din. Miss = Upar Report | 🚀 Future |
| **WhatsApp Bot 14448** | "Nazar" likh ke bhejo = Bot complaint lega | 🚀 Future |

### 3. TECH STACK
`Frontend` : HTML5, CSS3, Vanilla JS
`Backend` : Node.js, Express.js - Future
`Database` : LocalStorage -> MongoDB - Future
`AI` : Python - Future
`Blockchain` : IPFS + Polygon - Future
